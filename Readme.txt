To run project in any machine:
1) UiPath Studio version has to be 2026.0.200 (current community version)
2) Run process without changing anything, output will be generated in following location
Data\Output\Expense_Claims.xlsx

Assumptions:
1) File type can only be PDF, JPG, JPEG or PNG
2) Assume it runs once, so no need to manage versioning of output file
